# Epic 1 Context: 账号与设备发现

<!-- Compiled from planning artifacts. Edit freely. Regenerate with compile-epic-context if planning docs change. -->

## Goal

Epic 1 建立可信的系统入口：学生能注册、登录，并看到设备真实可约时段；管理员能维护设备与每日开放时间，使每个 30 分钟 slot 都由配置派生。配置变更不得悄悄破坏已有预约，同时交付单文件、单命令可运行的部署基线。成功标准：登录保护生效；slot 与开放时间严格一致；非法窗口被拒绝且不落库；收窄窗口导致越界时整次保存 409 且原配置不变；全部数据由一个数据库文件承载并可用一条命令启动。

## Stories

- Story 1.1: 学号注册、登录与管理员重置默认密码
- Story 1.2: 设备清单、开放时间维护与 slot 派生
- Story 1.3: 逐 slot 占用状态视图
- Story 1.4: 单文件部署、一条命令启动与种子导入

## Requirements & Constraints

- 管理员可新增、修改设备名称和每日开放时间，默认 08:00–22:00。
- 开放时间为本地墙钟 `HH:MM`，必须对齐整点或半点且开始早于结束；非法输入返回 400 且配置不变。
- slot 仅由开放时间按 30 分钟切分派生，覆盖 `[start, start+30min)`；不建手工 slot，窗口外不产生也不接受预约。
- 登录用户可查看设备名称与开放时间；未登录访问设备或 slot 页面返回 401。
- 收窄窗口若使已有占用越界，保存返回 409，配置与占用均不变；不得自动迁移或取消预约。
- 占用视图按设备与日期即时读库，能区分空闲、本人预约、他人预约、锁定、已过去、超出窗口六类状态；无推送、无轮询。
- 全部业务数据落在一个 SQLite 文件；运行时不依赖外部数据库、缓存、队列或云服务；一条命令启动，`GET /health` 返回 200。
- 停止服务后复制数据库到新路径重启，业务数据一致；运行期 `-wal` / `-shm` 不计为第二数据源。
- 缺少会话密钥或默认密码时启动失败，不得使用内置默认值。
- 种子导入按设备标识幂等、列顺序固定、整文件一个事务；任一行错误则整体回滚并报告行号；导入的管理员可登录。
- 密码只存加盐哈希，页面、响应、日志与导出不得出现明文。
- 核心页面在 375 px 与 1280 px 下可完成主流程，无横向滚动，无需安装客户端。

## Technical Decisions

- 分层单体：`web → app → data → SQLite`；模板只消费只读视图对象，不查库、不算时间；SQL 仅在数据层且参数化。
- 用标准库 `sqlite3`，默认 `data/lab.db`，路径可由环境变量覆盖；启用外键、WAL、忙等待；迁移按版本号启动时幂等补齐。
- slot 是派生量而非表；库中只存被占用的 `(equipment_id, slot_start)`；设备表存开放时间墙钟值，占用表是时段归属唯一事实源。
- 时刻统一存 20 字符 UTC 文本；时区换算只在专门工具模块，开放时间为唯一例外。
- 所有写操作经统一事务入口执行立即写事务；配置更新与审计同事务，仓储层不得自行控制事务。
- 状态码只在 Web 层统一映射；冲突响应携带可定位信息。
- 种子按设备业务标识 upsert；管理员账号由环境变量提供。
- 不引入 ORM、SPA/前端构建链、Docker、外部数据库、缓存、队列、WebSocket 或 SSE；配置只读环境变量。

## UX & Interaction Patterns

- 服务端完整渲染；变更走 HTML 表单 POST，成功 303 重定向，失败重渲染同页并保留上下文。
- 学生日视图与管理员周视图共用 slot 网格模板；模板只渲染服务端状态，不做时间运算。
- 状态同时提供可读文字与 `data-state` 属性，便于断言。
- 禁用 JavaScript 仍可完成主流程；样式手写，不依赖 CDN 或 UI 库。
- 页面声明响应式 viewport 并提供移动断点；设备清单直接展示名称与开放时间。

## Cross-Story Dependencies

- 1.1 提供登录会话与路由保护，是 1.2、1.3 设备与 slot 页面的前提。
- 1.2 定义设备数据、开放时间规则与 slot 派生；1.3 消费派生结果，1.4 依赖同一设备模型与迁移。
- 1.4 不得提前实现或复制 1.2 的设备校验规则。
- Epic 2 的预约依赖本 Epic 的开放时间与派生 slot；Epic 3 周视图复用本 Epic 的网格与设备数据。
