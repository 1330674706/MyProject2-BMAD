- (decision) 采用 Fast path：用户已锁定技术栈与五个决策点并指定输出路径，直接产出 ADR 集，不重复提问
- (constraint) 技术栈硬锁：Python 3.12 + Flask 3 + SQLite + Jinja2 + pytest；禁止 React、MySQL、Redis、消息队列、WebSocket（用户指令，覆盖一切选型讨论）
- (decision) 架构范式定为分层单体 + 事务脚本：web(路由/表单) -> app(用例) -> data(参数化 SQL) -> SQLite；依赖单向，templates 不查库，data 不抛 HTTP 异常
- (decision) ADR-001 唯一约束：occupancy 表上命名 UNIQUE 约束 uq_occupancy_slot(equipment_id, slot_start)，普通唯一索引，锁定与学生预约共用同一键空间；写入统一走 BEGIN IMMEDIATE，IntegrityError -> ROLLBACK -> 409
- (decision) ADR-002 单文件：data/lab.db，stdlib sqlite3 无 ORM，WAL + busy_timeout=5000 + synchronous=NORMAL，编号 SQL 迁移 + PRAGMA user_version
- (decision) ADR-003 服务端渲染：Jinja2 + 每页一个 GET 路由 + 表单 POST + 303 PRG；slot 用复选框多值提交，连续性/数量/窗口全部服务端校验；无 SPA、无构建步骤、无 JSON UI 接口
- (decision) ADR-004 会话登录：Flask 签名 Cookie 会话（itsdangerous），载荷 uid/role/pv；密码 werkzeug scrypt 哈希；管理员重置密码时 password_version+1，旧会话下一请求即失效；不做服务端 session 表、不做 JWT
- (decision) ADR-005 时间：所有时刻以定长 UTC 文本 YYYY-MM-DDTHH:MM:SSZ 存储；转换只发生在 core/timeutil.py；自然周在 Asia/Shanghai 计算后转 UTC 半开区间
- (decision) slot 是派生量不是数据：不建 slot 表，slot 集合 = f(equipment.open_start, open_end, date)，避免与开放时间漂移
- (version) 已在本机运行时核对版本：Flask 3.1.3 / Jinja2 3.1.6 / Werkzeug 3.1.3 / pytest 8.4.2 / itsdangerous 2.2.0；目标解释器 Python 3.12
- (decision) 部署：单进程多线程（Werkzeug threaded=True），每请求一个连接；不引入 Docker；data/ 必须在本机磁盘（WAL 不支持网络盘）
- (assumption) 会话有效期定为 12 小时绝对值，可调不阻塞；SECRET_KEY 必须来自环境变量且不少于 32 字节
- (question) 审计日志保留期限未定；首版不做清理，容量按 40 人规模每年约数十万行估算可接受
